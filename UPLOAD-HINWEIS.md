# GitHub-Upload-Hinweis

GitHub entpackt eine ZIP-Datei nicht automatisch in ein Repository.

Wenn du am PC bist:
1. ZIP lokal entpacken.
2. Im GitHub-Repository **Add file -> Upload files** öffnen.
3. Alle Dateien und Ordner *innerhalb* des Projektordners auswählen bzw. in den Browser ziehen.
4. Commit changes.

Wenn du nur eine ZIP-Datei hochladen kannst (z. B. am Handy), wird sie im Repository nur als ZIP gespeichert. Dann müssen die Dateien über einen Cloud-Arbeitsplatz wie GitHub Codespaces entpackt und committed werden.

Hinweis: Dieses Projekt ist ein Starter-Projekt. Der Build und die VexBot-Kompatibilität sind nicht verifiziert.
